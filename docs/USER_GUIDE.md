# User Guide

## Running The App

**Option 1: Local Virtual Environment**
```powershell
.\career_env\Scripts\activate
streamlit run app.py
```

**Option 2: Docker Deployment (Recommended for clean environment)**
```powershell
.\run_client.bat
```

Once running, open your browser and navigate to `http://localhost:8501`.

## How to Test All Features (Step-by-Step Guide)

To ensure the application is fully operational, follow these steps in your browser:

### 1. Test the Backend Connection & API Keys
- Look at the terminal/Docker logs when the app starts. It should output the loaded API keys and multi-model configuration (defaulting to the `kimi-k2.6` model).
- If keys are missing, update your `.env` file (see Environment Keys below) and restart the application.

### 2. Test "Career Match" 
- **Action**: Navigate to the **Career Match** tab.
- **Input**: Enter dummy data (e.g., Age 22, Education: Bachelor's). Select some hard skills, soft skills, and interests. Set the city development index.
- **Verify**: Click **Generate top matches**. Ensure it returns the top three careers, confidence scores, and missing critical skills without errors.

### 3. Test "Student Hub"
- **Action**: Navigate to the **Student Hub** tab.
- **Input**: Input GPA, college tier, and set skills (like DSA, web dev, SQL). Adjust the weekly study hours slider.
- **Verify**: Check that the placement forecaster outputs a probability percentage and the degree mapping plots correctly render visually using the local datasets.

### 4. Test "Pivot Dashboard"
- **Action**: Navigate to the **Pivot Dashboard** tab.
- **Input**: Select your current satisfaction levels, work-life balance, and years of experience.
- **Verify**: Check that the flight-risk calculator displays an urgency metric. View the lateral transition table to see if it ranks adjacent career moves correctly based on cosine similarity.

### 5. Test "Resume ATS"
- **Action**: Navigate to the **Resume ATS** tab.
- **Input**: Upload a sample PDF, DOCX, or TXT resume. 
- **Verify**: Ensure the analyzer outputs an ATS match score. Check for keyword gaps, formatting warnings, and action verb suggestions. Try the "Export ATS-friendly PDF" button and ensure a download prompts successfully. 
*(Note: Uploading image-based resumes will test the Kimi vision multimodal extraction).*

### 6. Test "Interview And Chat"
- **Action**: Navigate to the **Interview And Chat** tab.
- **Input**: Generate interview questions by pasting a target role. Paste a sample "STAR" method answer (Situation, Task, Action, Result) into the text box.
- **Verify**: Click to analyze the STAR answer to verify if it detects metrics and structure. 
- **Chatbot Test**: Type a question in the chat interface like "What are the latest AI career trends?" to trigger the RAG engine and API integration. Ensure a readable response is generated by the `kimi-k2.6` model.

## Detailed Component Documentation

### Career Match

1. Enter age and education.
2. Select hard skills, soft skills, and interests.
3. Add market context with city development index and company size.
4. Select **Generate top matches**.

The result shows the top three careers, raw model confidence, market-adjusted confidence, profile alignment, skills you already have, and critical missing skills.

## Student Hub

Use the placement forecaster with GPA, college tier, and competencies such as DSA, web development, SQL, and internship experience. The degree mapping section reads local raw datasets and plots where matching fields of study lead. The study habit tool estimates viability from weekly study hours, subject scores, and available baseline correlations.

## Pivot Dashboard

The flight-risk calculator estimates pivot urgency from satisfaction, work-life balance, and years of experience. The lateral transition table compares current skills against career skill maps and ranks adjacent moves by cosine similarity.

## Resume ATS

Upload PDF, DOCX, TXT, or supported image resumes. PDFs use `pdfplumber`, Word files use `python-docx`, text files are parsed locally, and image resumes require a configured Kimi key.

The analyzer provides:

- ATS match score using found keywords divided by total required keywords.
- Keywords found and keyword gaps.
- Formatting warnings.
- Weak action verb suggestions.
- Bullets missing measurable impact.
- Optional role-specific summary generation.
- ATS-friendly PDF resume export.

## Interview And Chat

Generate interview questions from the selected role and skills. Paste a STAR answer to check whether Situation, Task, Action, and Result are present and whether the Result includes a metric.

The audio sandbox records a mock answer through Streamlit. OpenAI transcription is optional and requires `OPENAI_API_KEYS`; filler-word analysis can run on either API transcript text or pasted transcript text.

The chatbot uses local dataset retrieval and the first configured chat provider in this order: Moonshot, OpenRouter, Fireworks, NVIDIA NIM, then Cloudflare Workers AI. Resume files can be attached in the chat input flow.

## Environment Keys

Copy `.env.example` to `.env` and set only the providers you plan to use.

```text
MOONSHOT_API_KEYS=["your_kimi_key"]
OPENROUTER_API_KEYS=["your_openrouter_key"]
OPENAI_API_KEYS=["your_openai_key"]
```

Local label-style entries such as `open router key 1: <secret>` are also supported so existing private `.env` files keep working. Use `python scripts/03_validate_api_keys.py` for a redacted key availability check.

Leave keys empty for offline model, student, pivot, ATS, and interview heuristic features.
